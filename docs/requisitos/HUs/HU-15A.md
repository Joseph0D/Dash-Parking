# HU-15A – Consulta de mis reservas

**Módulo:** reservas · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero consultar mis reservas actuales e históricas, para conocer su estado y detalles.

## Criterios de aceptación

- [ ] Veo estado (activa, cancelada o finalizada), parqueadero, zona, espacio, vehículo y fechas.
- [ ] Solo veo mis propias reservas.
- [ ] Puedo filtrar por estado y las reservas se ordenan de la más reciente a la más antigua.
- [ ] Si no tengo reservas, se muestra un mensaje.
