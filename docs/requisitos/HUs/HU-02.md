# HU-02 – Inicio de sesión

**Módulo:** cuentas · **Rol:** usuario

## Historia de usuario

> Como usuario registrado, quiero iniciar y cerrar sesión con mi correo y contraseña, para acceder de forma segura a mis reservas, vehículos y pagos.

## Criterios de aceptación

- [ ] Con credenciales correctas el sistema permite el acceso y me redirige a mi panel principal.
- [ ] Con credenciales incorrectas se muestra un mensaje genérico («Correo o contraseña incorrectos») sin revelar cuál dato falló.
- [ ] Si dejo algún campo vacío, se indica que es obligatorio.
- [ ] Si intento entrar a una sección privada sin sesión iniciada, soy redirigido al inicio de sesión.
- [ ] Puedo cerrar sesión y, después de hacerlo, no puedo ver información privada.

## Dependencias

[HU-01](HU-01.md).

## Pendientes por definir / notas técnicas

Definir duración de la sesión y bloqueo por intentos fallidos. La recuperación de contraseña, si se requiere, va en una historia aparte.

## Cambio respecto a la historia original

Se reformula el criterio de rutas privadas desde la perspectiva del usuario y se agregan cierre de sesión, campos vacíos y redirección.
