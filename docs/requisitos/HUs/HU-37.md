# HU-37 – QR de sesión para facilitar el pago

**Módulo:** pagos · **Rol:** cliente y operador

## Historia de usuario

> Como cliente con una sesión activa, quiero mostrar un QR temporal para que un operador pueda identificar la sesión y continuar el cobro sin buscarla manualmente.

## Criterios de aceptación

- [ ] El QR se asocia a una sesión activa y su token solo se puede validar una vez.
- [ ] Un token inválido, usado o asociado a una sesión cerrada se rechaza.
- [ ] Solo el titular consulta el QR; solo el operador o administrador autorizado lo valida.
- [ ] El QR identifica la sesión, pero no marca el pago como aprobado.

## Dependencias

[HU-20](HU-20.md), [HU-24](HU-24.md), [HU-30B](HU-30B.md).

## Requisito funcional

[RF-015](../RFs/RF-015_pago_qr.md).

## Estado

Implementado como QR de sesión/pago. No es el QR permanente por vehículo de [HU-36](HU-36.md).
