# HU-13 – Creación de reservas

**Módulo:** reservas · **Rol:** usuario

## Historia de usuario

> Como usuario con un vehículo registrado, quiero reservar un espacio compatible con mi vehículo antes de ingresar al parqueadero, para tener mi lugar garantizado a la hora que llegue.

## Criterios de aceptación

- [ ] Selecciono parqueadero, zona, vehículo, espacio y rango de fecha y hora.
- [ ] El tipo de vehículo debe corresponder al de la zona; si no, la reserva se rechaza con un mensaje claro.
- [ ] No se permiten espacios inactivos ni reservas con horario cruzado en el mismo espacio; el mensaje indica el motivo.
- [ ] Un mismo vehículo no puede tener dos reservas con horarios cruzados.
- [ ] La hora de inicio debe ser futura y la de fin posterior a la de inicio.
- [ ] La reserva se crea con estado 'activa' y el espacio queda bloqueado en ese horario para otros usuarios.
- [ ] Al crear la reserva se muestra una confirmación con el detalle.

## Pendientes por definir / notas técnicas

Definir duración máxima, anticipación mínima y si la reserva exige pago previo.

## Cambio respecto a la historia original

Absorbe la HU-14 (validación de compatibilidad), que era una regla y no una historia. Se agregan reglas de tiempo y confirmación.
