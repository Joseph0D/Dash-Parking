# HU-23 – Pago en línea (flujo base)

**Módulo:** tarifas-y-pagos · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero pagar mi ticket o reserva en línea, para pagar sin hacer filas ni usar efectivo.

## Criterios de aceptación

- [ ] Puedo elegir entre los medios de pago habilitados (PSE, Nequi, Daviplata y tarjeta).
- [ ] Soy redirigido a la pasarela de pagos de forma segura; el sistema no almacena datos de tarjeta.
- [ ] Se registra el pago con método, monto, referencia de la transacción y fecha, en estado 'Pendiente' hasta recibir la respuesta de la pasarela.
- [ ] El monto cobrado es el calculado en HU-22.
- [ ] No se permite pagar un ticket que ya está pagado.

## Dependencias

[HU-22](HU-22.md).

## Pendientes por definir / notas técnicas

Definir la pasarela de pagos. El DDL de metodo_pago solo admite 'PSE', 'Tarjeta Credito', 'Tarjeta Debito' y 'Efectivo': faltan Nequi y Daviplata.

## Cambio respecto a la historia original

Se divide por medio de pago (HU-23A, B y C) y el flujo base queda aquí. El criterio de aprobación pasa a HU-25.
