# HU-17 – Finalización automática de reservas

**Módulo:** reservas · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero que mi reserva se cierre automáticamente cuando ingrese mi vehículo o venza el tiempo, para que mi historial y la disponibilidad de espacios sean correctos.

## Criterios de aceptación

- [ ] Cuando se genera el ticket de ingreso, la reserva pasa a 'finalizada'.
- [ ] Una reserva activa sin ingreso pasa a 'finalizada' al vencer su horario más la tolerancia definida (15 minutos, supuesto).
- [ ] Al vencer sin ingreso, el espacio se libera; si hubo ingreso, queda ocupado.
- [ ] El cambio de estado se refleja en un máximo de 1 minuto tras el vencimiento.

## Dependencias

[HU-13](HU-13.md), [HU-18](HU-18.md).

## Pendientes por definir / notas técnicas

Definir el tiempo de tolerancia (15 minutos es un supuesto). Es un proceso automático del sistema: puede manejarse como tarea técnica.

## Cambio respecto a la historia original

Se reformula con un usuario real en vez de «Como sistema» y se agregan tiempos medibles.
