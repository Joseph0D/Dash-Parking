# HU-20 – Registro de salida del vehículo

**Módulo:** ingreso-y-salida · **Rol:** operador

## Historia de usuario

> Como operador, quiero registrar la salida del vehículo una vez pagado el ticket, para cerrar la permanencia y liberar el espacio.

## Criterios de aceptación

- [ ] Busco el ticket por placa.
- [ ] Solo se permite la salida si el pago está aprobado (ticket 'Pagado'); si no, se muestra el valor pendiente.
- [ ] Se guarda la fecha y hora de salida y el ticket pasa a 'Finalizado'.
- [ ] El espacio queda libre.

## Dependencias

[HU-18](HU-18.md) o [HU-19](HU-19.md), [HU-22](HU-22.md), [HU-23](HU-23.md) o [HU-24](HU-24.md).

## Pendientes por definir / notas técnicas

Definir un tiempo de gracia entre el pago y la salida.

## Cambio respecto a la historia original

Se agrega el caso de pago pendiente o rechazado.
