# HU-32 – Registro de cuenta de dueño

**Módulo:** cuentas · **Rol:** visitante

## Historia de usuario

> Como dueño de un parqueadero, quiero crear una cuenta de dueño para registrar y administrar mis parqueaderos en la plataforma.

## Criterios de aceptación

- [ ] Puedo elegir el tipo de cuenta cliente o dueño durante el registro.
- [ ] El sistema no permite autorregistrarse como operador ni administrador de plataforma.
- [ ] La cuenta de dueño queda vinculada únicamente a los parqueaderos que registre o que le sean asignados.
- [ ] Puedo iniciar sesión y acceder al panel de dueño después de registrarme.

## Dependencias

[HU-01](HU-01.md), [HU-02](HU-02.md), [HU-30A](HU-30A.md), [HU-33](HU-33.md).

## Requisito funcional

[RF-016](../RFs/RF-016_registro_de_cuenta_cliente.md), [RF-019](../RFs/RF-019_gestion_parqueaderos_dueno.md).

## Estado

Implementado para autorregistro cliente/dueño; los criterios deben conservarse en las pruebas de registro y permisos.
