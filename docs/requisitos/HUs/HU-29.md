# HU-29 – Control de capacidad y ocupación

**Módulo:** administración · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero controlar la capacidad y ocupación de cada zona y parqueadero, para evitar sobrecupo y conocer los espacios libres.

## Criterios de aceptación

- [ ] Veo capacidad total, espacios ocupados, reservados y libres por zona y por parqueadero.
- [ ] El sistema bloquea reservas e ingresos cuando una zona está llena.
- [ ] Los datos se actualizan en un máximo de 5 segundos o al refrescar la pantalla.
- [ ] Las cifras coinciden con las que ven los usuarios en HU-12.

## Dependencias

[HU-10](HU-10.md), [HU-12](HU-12.md).

## Pendientes por definir / notas técnicas

Definir el tiempo de actualización (supuesto de 5 segundos).

## Cambio respecto a la historia original

Se reemplaza «tiempo real» por un tiempo medible y se alinea con HU-12 para evitar el solapamiento.
