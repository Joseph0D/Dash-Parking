# HU-27B – Historial de pagos (administrador)

**Módulo:** tarifas-y-pagos · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero consultar los pagos de todos los usuarios, para hacer seguimiento a los ingresos del parqueadero.

## Criterios de aceptación

- [ ] Veo los pagos de todos los usuarios con usuario, parqueadero, monto, método, estado y fecha.
- [ ] Puedo filtrar por usuario, parqueadero, fecha, estado y método de pago.
- [ ] Solo el rol administrador accede a esta consulta.
