# HU-28B – Recordatorios y vencimiento de reservas

**Módulo:** notificaciones · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero recibir un recordatorio antes de mi reserva y un aviso cuando venza, para no perder mi reserva.

## Criterios de aceptación

- [ ] Recibo un recordatorio 30 minutos antes de la hora de inicio (supuesto).
- [ ] Recibo un aviso cuando mi reserva venció sin ingreso.
- [ ] No recibo recordatorios de reservas canceladas.

## Dependencias

[HU-13](HU-13.md), [HU-17](HU-17.md).

## Pendientes por definir / notas técnicas

Definir con cuánta antelación se envía el recordatorio (30 minutos es un supuesto).
