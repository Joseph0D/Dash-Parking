# HU-04 – Registro de vehículos

**Módulo:** vehículos · **Rol:** usuario

## Historia de usuario

> Como usuario con sesión iniciada, quiero registrar mis vehículos, para asociarlos a mis reservas y tickets.

## Criterios de aceptación

- [ ] Puedo elegir el tipo de vehículo: carro, moto, bicicleta, moto eléctrica o patineta.
- [ ] El formulario solicita placa, marca, modelo y color; todos son obligatorios, excepto la placa en bicicleta y patineta.
- [ ] La placa debe tener un formato válido según el tipo de vehículo.
- [ ] No se permite registrar una placa que ya exista en el sistema; se muestra un mensaje claro.
- [ ] Si falta algún campo obligatorio se indica cuál.
- [ ] Al registrar con éxito se muestra una confirmación y el vehículo aparece en mi lista, asociado a mi cuenta.
