# HU-21 – Gestión de tarifas

**Módulo:** tarifas-y-pagos · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero definir tarifas por parqueadero y tipo de vehículo con su vigencia, para cobrar correctamente según el tipo de vehículo.

## Criterios de aceptación

- [ ] Puedo definir el valor por minuto y el valor por día (tope diario); los valores deben ser mayores que cero.
- [ ] Registro la fecha de inicio y de fin de vigencia, con el fin posterior al inicio.
- [ ] No se permiten tarifas vigentes cruzadas para el mismo parqueadero y tipo de vehículo.
- [ ] Puedo consultar y editar tarifas; editar una tarifa no cambia los valores de tickets ya cobrados.
