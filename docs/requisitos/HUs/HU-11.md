# HU-11 – Búsqueda de parqueaderos

**Módulo:** reservas · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero buscar parqueaderos y filtrar por tipo de vehículo, para encontrar el que mejor se ajuste a mi necesidad.

## Criterios de aceptación

- [ ] Puedo buscar parqueaderos por nombre.
- [ ] Puedo localizar una dirección y consultar parqueaderos en el mapa sin una API key propietaria.
- [ ] Cada resultado muestra nombre, dirección, teléfono, zonas y tarifa vigente.
- [ ] Puedo filtrar por tipo de vehículo y solo aparecen los parqueaderos con una zona de ese tipo.
- [ ] Puedo comparar ubicación y disponibilidad por fecha, horario y tipo de vehículo.
- [ ] Solo aparecen parqueaderos activos.
- [ ] Si no hay resultados, se muestra un mensaje.
- [x] Puedo seleccionar una ubicación en el mapa de Bogotá y abrir su disponibilidad.
- [x] Los parqueaderos de demostración se identifican claramente como tales.

## Dependencias

[HU-07A](HU-07A.md), [HU-08](HU-08.md), [HU-21](HU-21.md).

## Pendientes por definir / notas técnicas

La búsqueda por nombre, filtros y búsqueda explícita de dirección deben validarse en la interfaz
pública. Nominatim no se consulta automáticamente.

## Cambio respecto a la historia original

La búsqueda textual y los filtros se conservan como pendientes hasta que estén disponibles en
la interfaz pública; el mapa de demostración no implica que esos parqueaderos sean negocios
reales.

Se agregan la búsqueda por nombre, ubicación geográfica y el caso sin resultados.
