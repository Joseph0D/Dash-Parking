# HU-11 – Búsqueda de parqueaderos

**Módulo:** reservas · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero buscar parqueaderos y filtrar por tipo de vehículo, para encontrar el que mejor se ajuste a mi necesidad.

## Criterios de aceptación

- [ ] Puedo buscar parqueaderos por nombre.
- [ ] Cada resultado muestra nombre, dirección, teléfono, zonas y tarifa vigente.
- [ ] Puedo filtrar por tipo de vehículo y solo aparecen los parqueaderos con una zona de ese tipo.
- [ ] Solo aparecen parqueaderos activos.
- [ ] Si no hay resultados, se muestra un mensaje.

## Dependencias

[HU-07A](HU-07A.md), [HU-08](HU-08.md), [HU-21](HU-21.md).

## Pendientes por definir / notas técnicas

Ninguno.

## Cambio respecto a la historia original

Se agrega la búsqueda por nombre (el título la prometía y no había criterio) y el caso sin resultados.
