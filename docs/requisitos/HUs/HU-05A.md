# HU-05A – Consulta de vehículos

**Módulo:** vehículos · **Rol:** usuario

## Historia de usuario

> Como usuario con sesión iniciada, quiero ver la lista de mis vehículos, para saber cuáles tengo registrados.

## Criterios de aceptación

- [ ] Veo la lista de mis vehículos con placa, marca, modelo, color y tipo.
- [ ] Solo veo los vehículos de mi cuenta.
- [ ] Si no tengo vehículos, se muestra un mensaje que me invita a registrar uno.
