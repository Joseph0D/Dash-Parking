# HU-03 – Gestión del perfil de usuario

**Módulo:** cuentas · **Rol:** usuario

## Historia de usuario

> Como usuario con sesión iniciada, quiero consultar y actualizar mis datos personales, para mantener mi información de contacto al día.

## Criterios de aceptación

- [ ] Al entrar a mi perfil veo mis datos actuales (nombres, apellidos, documento, teléfono y correo).
- [ ] Puedo modificar nombres, apellidos, teléfono y correo; el documento se muestra pero no es editable.
- [ ] Los campos conservan las validaciones del registro (obligatorios, correo válido, teléfono solo numérico).
- [ ] Si el correo ingresado ya pertenece a otro usuario no se guarda el cambio y se muestra un mensaje claro; si no cambio mi correo, no se valida contra mí mismo.
- [ ] Al guardar con éxito se muestra una confirmación y el perfil presenta los datos actualizados.
- [ ] Si cancelo la edición, no se guarda ningún cambio.
