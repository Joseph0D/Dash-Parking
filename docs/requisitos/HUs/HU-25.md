# HU-25 – Confirmación y estado del pago

**Módulo:** tarifas-y-pagos · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero conocer si mi pago fue aprobado, pendiente o rechazado, para tener certeza del resultado y poder reintentar.

## Criterios de aceptación

- [ ] El estado del pago se actualiza según la respuesta de la pasarela.
- [ ] Si está pendiente, se muestra un mensaje de «pago en proceso» y puedo consultar su estado luego.
- [ ] Si es rechazado, se muestra el motivo y puedo reintentar el pago del mismo ticket.
- [ ] Si es aprobado, el ticket pasa a 'Pagado' y recibo una notificación (HU-28C).

## Dependencias

[HU-23](HU-23.md), [HU-28C](HU-28C.md).

## Pendientes por definir / notas técnicas

Definir el tiempo máximo en que un pago puede quedar pendiente.

## Cambio respecto a la historia original

Absorbe la aprobación que estaba en HU-23 y se agrega el estado pendiente.
