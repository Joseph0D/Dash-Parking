# HU-35 – Recuperación de contraseña por correo

**Módulo:** autenticación · **Rol:** usuario o dueño

## Historia de usuario

> Como usuario que olvidó su contraseña, quiero recibir un enlace seguro por correo para definir una nueva y recuperar el acceso a mi cuenta.

## Criterios de aceptación

- [ ] La solicitud siempre muestra la misma respuesta, exista o no la cuenta.
- [ ] El sistema envía un enlace por SMTP con un token aleatorio de un solo uso, almacenado únicamente como hash y con vencimiento de 30 minutos.
- [ ] La nueva contraseña cumple las reglas de seguridad vigentes y el token queda invalidado después de usarse.
- [ ] Se limitan las solicitudes a tres por correo y diez por IP por hora.
- [ ] Las credenciales SMTP solo se configuran mediante variables de entorno.

## Dependencias

[HU-01](HU-01.md), [HU-02](HU-02.md).

## Requisito funcional

[RF-021](../RFs/RF-021_recuperacion_contrasena.md).

## Estado

Implementado; el usuario confirmó la recepción de un correo real con Brevo SMTP.
