# HU-06 – Gestión de tipos de vehículo

**Módulo:** vehículos · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero crear, consultar y actualizar los tipos de vehículo, para definir qué vehículos admite el sistema.

## Criterios de aceptación

- [ ] Puedo crear un tipo con nombre y descripción; el nombre no puede repetirse.
- [ ] El sistema incluye por defecto los tipos carro, moto, bicicleta, moto eléctrica y patineta.
- [ ] Puedo ver la lista de tipos y editar el nombre y la descripción de uno existente.
- [ ] Si edito un tipo en uso, los cambios se ven en las zonas, tarifas y vehículos que lo usan sin perder la asociación.

## Dependencias

[HU-02](HU-02.md), [HU-30B](HU-30B.md).

## Pendientes por definir / notas técnicas

Definir si los tipos se podrán desactivar.

## Cambio respecto a la historia original

El criterio 3 original («los cambios se reflejan…») se hace verificable y se agrega la unicidad del nombre.
