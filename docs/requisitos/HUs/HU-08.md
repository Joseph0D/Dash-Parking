# HU-08 – Gestión de zonas

**Módulo:** parqueaderos · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero crear y administrar las zonas de cada parqueadero según el tipo de vehículo, para organizar los espacios en zonas por tipo de vehículo.

## Criterios de aceptación

- [ ] Puedo crear una zona con nombre, parqueadero, tipo de vehículo y capacidad.
- [ ] El tipo de vehículo debe existir en los tipos definidos en HU-06 (no solo carros, motos y bicicletas).
- [ ] La suma de capacidades de las zonas no supera la capacidad total del parqueadero; si la supera, se muestra un mensaje.
- [ ] Puedo consultar las zonas de cada parqueadero.
- [ ] Puedo editar el nombre y la capacidad de una zona; la capacidad no puede ser menor que los espacios ya creados.
