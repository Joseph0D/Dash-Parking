# HU-05B – Edición de vehículos

**Módulo:** vehículos · **Rol:** usuario

## Historia de usuario

> Como usuario con sesión iniciada, quiero editar los datos de uno de mis vehículos, para mantener su información actualizada.

## Criterios de aceptación

- [ ] Puedo modificar placa, marca, modelo y color de un vehículo propio.
- [ ] La placa conserva las reglas de formato y unicidad de HU-04.
- [ ] No puedo cambiar el tipo de vehículo si tiene una reserva o ticket activo.
- [ ] Al guardar se muestra una confirmación y la lista refleja los cambios.
- [ ] Solo puedo editar vehículos de mi cuenta.

## Dependencias

[HU-04](HU-04.md), [HU-05A](HU-05A.md).
