# HU-23A – Pago con PSE

**Módulo:** tarifas-y-pagos · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero pagar con PSE, para pagar directamente desde mi cuenta bancaria.

## Criterios de aceptación

- [ ] Puedo seleccionar mi banco de la lista que ofrece la pasarela.
- [ ] Soy redirigido al banco y, al terminar, regreso a la plataforma con el resultado.
- [ ] El resultado queda registrado como 'Aprobado', 'Pendiente' o 'Rechazado' (HU-25).

## Dependencias

[HU-23](HU-23.md).

Ninguno.
