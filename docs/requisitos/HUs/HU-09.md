# HU-09 – Gestión de tipos de espacio

**Módulo:** parqueaderos · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero definir y mantener los tipos de espacio, para clasificar los espacios según sus características y asignarlos correctamente.

## Criterios de aceptación

- [ ] Puedo crear un tipo de espacio con nombre y descripción; el nombre no puede repetirse.
- [ ] Puedo ver la lista y editar un tipo existente.
- [ ] Un tipo creado queda disponible al crear espacios (HU-10).

## Dependencias

[HU-02](HU-02.md), [HU-30B](HU-30B.md).

## Pendientes por definir / notas técnicas

Aclarar para qué sirve la clasificación (ejemplos: normal, cubierto, preferencial).

## Cambio respecto a la historia original

Se refuerza el «para» (valor débil) y se agrega la unicidad del nombre.
