# HU-27A – Historial de pagos y facturas

**Módulo:** tarifas-y-pagos · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero consultar mi historial de pagos y comprobantes, para llevar control de mis gastos en parqueaderos.

## Criterios de aceptación

- [ ] Veo mis pagos con fecha, parqueadero, monto, método y estado.
- [ ] Puedo filtrar por fecha, estado y método de pago.
- [ ] Solo veo mis propios pagos y puedo abrir el comprobante de cada uno.
- [ ] Los pagos se ordenan del más reciente al más antiguo.
