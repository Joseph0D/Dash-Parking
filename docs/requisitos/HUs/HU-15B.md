# HU-15B – Consulta de reservas (administrador)

**Módulo:** reservas · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero consultar las reservas de todos los usuarios, para supervisar la operación y atender reclamos.

## Criterios de aceptación

- [ ] Veo las reservas de todos los usuarios con usuario, estado, parqueadero, zona, espacio, vehículo y fechas.
- [ ] Puedo filtrar por usuario, parqueadero, estado y fecha.
- [ ] Solo el rol administrador accede a esta consulta.
