# HU-19 – Ingreso sin reserva

**Módulo:** ingreso-y-salida · **Rol:** operador

## Historia de usuario

> Como operador, quiero registrar el ingreso de un vehículo sin reserva, para atender a todos los usuarios que lleguen al parqueadero.

## Criterios de aceptación

- [ ] Ingreso la placa y el tipo de vehículo.
- [ ] El sistema asigna un espacio libre, activo y compatible con el tipo de vehículo.
- [ ] Se crea un ticket con estado 'Activo' sin reserva asociada y el espacio pasa a ocupado.
- [ ] Si la zona está llena, se informa que no hay disponibilidad y no se genera ticket.
- [ ] No se permite ingresar un vehículo que ya tiene un ticket activo.

## Dependencias

[HU-10](HU-10.md), [HU-12](HU-12.md).
