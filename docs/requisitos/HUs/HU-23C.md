# HU-23C – Pago con tarjeta

**Módulo:** tarifas-y-pagos · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero pagar con tarjeta de crédito o débito, para pagar sin efectivo.

## Criterios de aceptación

- [ ] Puedo elegir tarjeta de crédito o débito y diligenciar los datos en el formulario seguro de la pasarela.
- [ ] El sistema no almacena el número completo ni el código de seguridad de la tarjeta.
- [ ] El resultado queda registrado como 'Aprobado', 'Pendiente' o 'Rechazado' (HU-25).
