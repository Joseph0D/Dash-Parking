# HU-24 – Pago en efectivo

**Módulo:** tarifas-y-pagos · **Rol:** operador

## Historia de usuario

> Como operador, quiero registrar pagos en efectivo en el punto de atención, para atender a los usuarios que no pagan en línea.

## Criterios de aceptación

- [ ] Busco el ticket y veo el valor calculado a pagar.
- [ ] Ingreso el monto recibido; no puede ser menor al total y se muestra el cambio a devolver.
- [ ] Se registra el pago con método 'Efectivo', monto y fecha, con estado 'Aprobado'; el ticket pasa a 'Pagado' y queda asociado a la tarifa aplicada.
- [ ] Se genera el comprobante de pago (HU-26).
- [ ] No se permite registrar un segundo pago para un ticket ya pagado.

## Dependencias

[HU-22](HU-22.md).

## Pendientes por definir / notas técnicas

Ninguno.

## Cambio respecto a la historia original

Se agregan el monto recibido, el cambio, el comprobante y la restricción de doble pago.
