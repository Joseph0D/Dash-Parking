# HU-31 – Reportes de ocupación e ingresos

**Módulo:** administración · **Rol:** administrador

## Historia de usuario

> Como administrador, quiero generar reportes de ocupación, reservas e ingresos, para tomar decisiones sobre la operación del parqueadero.

## Criterios de aceptación

- [ ] Puedo filtrar por periodo, zona, tipo de vehículo y método de pago.
- [ ] El reporte muestra ocupación, reservas realizadas y canceladas e ingresos totales.
- [ ] Puedo exportar el reporte en PDF y Excel (supuesto).
- [ ] Si no hay datos para los filtros, se muestra un mensaje.
- [ ] Solo el administrador accede a los reportes.
