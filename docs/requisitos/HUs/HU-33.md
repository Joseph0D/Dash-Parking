# HU-33 – Gestión de parqueaderos propios

**Módulo:** parqueaderos · **Rol:** dueño

## Historia de usuario

> Como dueño, quiero crear y administrar uno o varios parqueaderos con su ubicación, horarios, espacios y tarifas, para ofrecer cupos compatibles con distintos vehículos.

## Criterios de aceptación

- [ ] Puedo crear y editar nombre, dirección, ubicación geográfica y horarios semanales de cada parqueadero.
- [ ] Puedo marcar o mover el punto en un mapa y buscar una dirección; las coordenadas quedan guardadas.
- [ ] Configuro cantidades y tarifas por tipo de vehículo admitido.
- [ ] Puedo consultar la disponibilidad de espacios de cada tipo.
- [ ] Un parqueadero sin horarios configurados no acepta nuevas reservas.
- [ ] No puedo modificar ni consultar parqueaderos que pertenecen a otro dueño.
- [ ] Los cambios incompatibles con reservas confirmadas o sesiones activas se rechazan con una explicación.
