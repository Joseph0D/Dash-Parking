# HU-16 – Cancelación de reservas

**Módulo:** reservas · **Rol:** usuario

## Historia de usuario

> Como usuario, quiero cancelar una reserva activa antes de su hora de inicio, para liberar el espacio si no voy a usarlo.

## Criterios de aceptación

- [ ] Solo puedo cancelar mis reservas con estado 'activa' y antes de su hora de inicio.
- [ ] Antes de cancelar, el sistema pide confirmación.
- [ ] El estado cambia a 'cancelada' y el espacio queda disponible para otros usuarios.
- [ ] Recibo una notificación de la cancelación (HU-28A).

## Dependencias

[HU-13](HU-13.md), [HU-28A](HU-28A.md).

## Pendientes por definir / notas técnicas

Definir si hay reembolso y un tiempo mínimo de anticipación para cancelar.

## Cambio respecto a la historia original

Se agregan confirmación, restricción de propiedad y notificación.
