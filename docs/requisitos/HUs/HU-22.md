# HU-22 – Cálculo automático del valor a pagar

**Módulo:** tarifas-y-pagos · **Rol:** usuario

## Historia de usuario

> Como usuario con un ticket activo, quiero ver el valor calculado según mi tiempo de permanencia, para saber cuánto debo pagar antes de hacerlo.

## Criterios de aceptación

- [ ] El cálculo usa la fecha y hora de entrada, la de salida o consulta, y la tarifa vigente del parqueadero y tipo de vehículo.
- [ ] El total es el tiempo en minutos por el valor por minuto, con el tope diario cuando se supere (ejemplo: carro, 70 minutos a $500 por minuto = $35.000, si no aplica el tope).
- [ ] Antes de confirmar el pago se muestra el desglose: entrada, salida, minutos, tarifa y total.
- [ ] El monto total queda guardado en el pago.

## Dependencias

[HU-18](HU-18.md) o [HU-19](HU-19.md), [HU-21](HU-21.md).

## Pendientes por definir / notas técnicas

Definir regla de redondeo, tope diario y minutos de gracia (sin esto no es verificable).

## Cambio respecto a la historia original

Se hace verificable con una fórmula y un ejemplo, y se agrega el desglose.
