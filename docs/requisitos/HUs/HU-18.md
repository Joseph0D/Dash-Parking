# HU-18 – Ingreso con reserva

**Módulo:** ingreso-y-salida · **Rol:** operador

## Historia de usuario

> Como operador, quiero registrar la entrada de un vehículo con reserva generando un ticket, para controlar el tiempo de permanencia.

## Criterios de aceptación

- [ ] Busco la reserva por placa del vehículo.
- [ ] El sistema valida que la reserva esté activa, dentro del horario permitido y que el vehículo coincida con el reservado; si no, informa el motivo.
- [ ] Se crea un ticket con estado 'Activo' con vehículo, espacio, reserva y fecha y hora de entrada.
- [ ] El espacio pasa a estado ocupado y la reserva a 'finalizada'.
