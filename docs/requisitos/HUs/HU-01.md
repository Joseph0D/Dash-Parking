# HU-01 – Registro de usuarios

**Módulo:** cuentas · **Rol:** usuario

## Historia de usuario

> Como visitante nuevo, quiero crear una cuenta en la plataforma, para poder acceder a ella y reservar espacios.

## Criterios de aceptación

- [ ] El formulario solicita nombres, apellidos, tipo y número de documento, teléfono, correo y contraseña; todos son obligatorios y, si falta alguno, se indica cuál.
- [ ] El correo debe tener formato válido y el teléfono solo admite números.
- [ ] La contraseña debe tener una longitud mínima de 8 caracteres.
- [ ] No se permite registrar un correo o un documento que ya existan; se muestra un mensaje claro indicando cuál se repite.
- [ ] Al registrarse con éxito se muestra una confirmación y el usuario queda habilitado para iniciar sesión.

## Dependencias

Ninguna.

## Pendientes por definir / notas técnicas

Definir tipos de documento admitidos (CC, CE, pasaporte) y reglas de contraseña (8 caracteres es un supuesto). Nota técnica: la contraseña se almacena cifrada y se guarda la fecha de registro.

Se quitó la lista de campos de la historia (pasa a criterios). El cifrado y la fecha pasan a nota técnica. Se agregan validaciones de formato y el resultado del registro.
